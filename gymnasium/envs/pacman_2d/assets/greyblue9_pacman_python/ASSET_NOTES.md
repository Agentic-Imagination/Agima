# greyblue9/pacman-python Assets

These GIF assets are vendored from `greyblue9/pacman-python`:

https://github.com/greyblue9/pacman-python

Vendored source paths:

- `pacman/res/tiles/*.gif`
- `pacman/res/sprite/*.gif`

The custom `Pacman2DEnv` uses these files only for rendering. Maze generation,
Pacman actions, ghost policy, oracle planning, rewards, and dataset generation
remain implemented locally in VisGym.

The upstream repository does not include a conventional LICENSE file. Its
README grants informal reuse permission: "Feel free to slice and dice it up
however you like and redistribute it; I just ask that you give me some credit
and let me know about it..." Keep this attribution note with the vendored
assets.
