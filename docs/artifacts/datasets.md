# Datasets

[Artifact overview](README.md) · [Download guide](../data-and-models.md)

Links point to fixed Hugging Face revisions. The JSON manifest lists the files to download, their sizes, and available content hashes.

The manifest identifies training shards and held-out evaluation files. Pass a held-out file or a directory containing only the intended test split to the evaluator. Loading an entire repository recursively can mix training and test rows.
